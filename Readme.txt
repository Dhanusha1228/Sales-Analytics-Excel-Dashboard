# 📊 Sales Performance Dashboard (Excel)

## 📌 Project Overview
This project is an interactive Sales Performance Dashboard created in Microsoft Excel. It provides a quick overview of business performance using Pivot Tables, Pivot Charts, and KPI cards.

---

## 🎯 Objective
To analyze sales data and present key business insights in a simple and interactive dashboard.

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Dashboard Design

---

## 📂 Dataset
The dataset contains sales information including:
- Product
- Category
- City
- Quantity
- Revenue
- Order Details

---

## 📈 Dashboard KPIs
- **Total Revenue:** ₹11,24,400
- **Total Orders:** 50
- **Total Quantity Sold:** 123

---

## 📊 Dashboard Visualizations
1. Sales Performance by Category
2. Sales by City
3. Top Selling Products

---

## 🔍 Key Insights
- Electronics generated the highest revenue.
- Pune recorded the highest sales among all cities.
- Laptop was the best-selling product.
- Furniture contributed less revenue than Electronics.
